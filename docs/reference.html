Reference

Lookup tables for the values and platform features behind mote. This page is reference material, not a second guide.

Tokens

Every knob in the library is a custom property. Page CSS that reads these re-themes automatically — check for a token before writing a value. The palette redefines itself per theme; the layout and density tokens are inline defaults — set them per use, on the element or a selector. The status contract (--mote-status / --mote-status-soft) is covered in Helpers — status classes.

Fonts

mote declares font stacks only — it embeds nothing and requires nothing. Out of the box it falls back to your system fonts. For the full experience, add Inter and Commit Mono (both free, SIL OFL):

<!-- CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5/index.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fontsource/commit-mono@5/index.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fontsource/commit-mono@5/700.css">

<!-- or self-host -->
npm install @fontsource-variable/inter @fontsource/commit-mono

Browser support

Modern evergreen browsers. The core needs color-mix(): Chrome/Edge 111+, Firefox 113+, Safari 16.2+. Component niceties ride on Baseline 2024 platform features and degrade gracefully:

FeatureUsed forFallback
popoverTooltips, menus, toastsSupported everywhere since 2024
details nameExclusive accordionsUnsupported: groups stay independent
@starting-style, allow-discreteOpen/close animationsInstant open/close
:user-invalidForm validation stylingNo live feedback border
CSS anchor positioningPopovers next to their triggerViewport-centered popover
details::details-content + interpolate-sizeAccordion open/close animationInstant toggle
